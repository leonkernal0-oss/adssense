# AdSSense

Cool offline tools website — currency converter, password generator, QR codes, unit converter, color picker, text tools, Base64, and hash generator.

Everything runs 100% in the browser. No backend. Ready for AdSense / ads.

## Tools included

- **Currency Converter** — offline rates (editable, saved in localStorage)
- **Password Generator** — crypto-secure, custom length & charset
- **QR Code Generator** — pure offline, no external API
- **Unit Converter** — length, weight, temperature, area, volume, speed, data
- **Color Picker** — HEX / RGB / HSL / CMYK
- **Text Tools** — upper/lower/title/reverse/slug + char/word/line count
- **Base64** — encode & decode
- **Hash** — SHA-1 / SHA-256 / SHA-384 / SHA-512 (Web Crypto)

## Deploy

Just host `index.html` anywhere (GitHub Pages, Netlify, Vercel, etc.).

### GitHub Pages
1. Settings → Pages → Source: Deploy from a branch
2. Branch: `main` / root
3. Site will be at `https://leonkernal0-oss.github.io/adssense/`

## Ads

Two placeholder slots are already in the page (`#ad-top` and `#ad-bottom`).  
Replace the comment blocks with your AdSense code when ready.
